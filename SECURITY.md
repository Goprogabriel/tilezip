# Security and privacy

TileZip is a static, client-side tool. It has no accounts, API keys, server-side file processing or database.

User files are checked by file signature, decoded by the browser and rendered to a local canvas. SVG input is deliberately unsupported. ZIP filenames are generated by the app rather than taken from uploaded archive paths. Message text is drawn to a canvas and assigned to DOM text properties, never inserted as untrusted HTML.

The application makes no network upload requests. Its page-level Content Security Policy blocks connection APIs and remote scripts. The hosting provider still receives requests for ordinary static assets.

Image decoding and memory safety ultimately depend on the browser. Keep your browser updated; very large images can still exceed device-specific limits. The app limits file size and decoded dimensions, releases temporary canvases and object URLs, and provides cancellation.

To report a vulnerability, use GitHub's private vulnerability reporting for this repository if available. Otherwise open a minimal issue without publishing sensitive images, personal data or exploit details, and request a private contact method. Never include API keys or credentials in an issue.
